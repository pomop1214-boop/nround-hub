## 모듈 구성

| 화면 | 경로 | 내용 |
|---|---|---|
| 로그인 | `/login` | 이름 + 비밀번호. 로그인 안 하면 다른 화면에 못 들어가요 |
| 홈 | `/` | 공지사항 + 알림 구독 |
| 활동 투표 | `/vote` | 크루원이 응답하는 화면. 만들기·수정·집계는 관리자에서 |
| N.R 캐치마이크 | `/waiting` | 부르기 대기열 (기존 NewRoundwaiting 이식) |
| 회비 입금 확인 | `/dues` | 이번 회차 납부 현황 + 모임 계좌 |
| 크루 규정 | `/rules` | 규정·매뉴얼 위키 + 동의 체크 |
| 비밀번호 변경 | `/password` | 본인이 자기 비밀번호를 바꿔요 |
| 마이 | `/me` | 다가오는 일정 · 내 회비 · 내 투표 · 규정 확인 |
| 투표 결과 | `/vote/report/[id]` | 인쇄용 집계표 (PDF 저장) |
| 관리자 | `/admin` | 요청 · 공지 · 투표 · 일정 · 크루원 · 회비 회차 · 미확인 · 규정 |

하단 탭: 홈 · 투표 · 캐치마이크 · 규정 · 마이

회비 납부 명단(운영자용)은 탭에서 빠졌고, `관리자 → 회비 회차` 탭 위쪽 카드로 들어갑니다.

## Supabase 서울 이전

기존 프로젝트가 인도 뭄바이(ap-south-1)에 있어 한국에서 쓰면 왕복 지연이 큽니다.
서울로 옮기는 절차는 다음과 같습니다.

1. Supabase에서 **New project** → Region: **Northeast Asia (Seoul)** 로 새로 만들기
2. 새 프로젝트에서 `supabase/schema.sql` 실행
3. **기존** 프로젝트에서 `supabase/migrate-1-export.sql` 실행 → 나온 INSERT 문 전체 복사
4. 복사한 것을 **새** 프로젝트에서 실행
5. 새 프로젝트의 Settings → API Keys 에서 URL / publishable / secret 키를 복사
6. Vercel → 프로젝트 → Settings → Environment Variables 에서 아래 3개를 새 값으로 교체
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
7. Deployments → 최신 배포 → Redeploy

비밀번호는 해시를 그대로 옮기므로 **크루원들은 쓰던 비밀번호를 계속 씁니다.**
알림 구독(`push_subscriptions`)은 옮기지 않으므로 각자 "공지 알림 켜기"를 다시 눌러야 합니다.

같은 프로젝트를 쓰는 다른 앱(버스킹 곡신청, 토요일 RSVP, 부르기 대기열)은
`supabase/migrate-2-other-apps.sql` 을 참고하세요. 이 앱들의 코드에 적힌
Supabase 주소·키도 함께 바꿔야 합니다.

## 0. 처음부터 다시 하고 싶을 때

1. `supabase/reset.sql` 전체를 SQL Editor에 붙여넣고 Run
2. 이어서 `supabase/schema.sql` 전체를 붙여넣고 Run

허브가 만든 테이블만 지우고 새로 만듭니다.
같은 Supabase 프로젝트에 함께 있는 아래 앱들은 **건드리지 않습니다.**

| 남는 것 | 쓰는 앱 |
|---|---|
| `nround_queue` | 캐치마이크 대기열 |
| `busking_submissions`, `busking_config` | 버스킹 곡신청 |
| `saturday_poll_config`, `saturday_poll_responses` | 토요일 RSVP |

⚠️ 알림 구독은 초기화됩니다. 크루원들이 각자 홈 화면에서
"공지 알림 켜기"를 다시 눌러야 해요.

## 1. Supabase

`supabase/schema.sql` 전체를 SQL Editor에 붙여넣고 Run. **한 번만** 하면 됩니다.
크루원 이름·회비 금액은 SQL이 아니라 앱의 관리자 화면에서 넣습니다.

## 2. Vercel

GitHub 저장소를 Import하고, `환경변수-복사용.txt` 의 9개를 Environment Variables에 넣은 뒤 Deploy.
Root Directory는 기본값(`./`) 그대로 두세요.

## 3. 첫 로그인 문제

배포 직후에는 크루원이 한 명도 없어서 로그인할 계정이 없습니다.
이때는 **로그인 화면 아래에 `관리자 화면으로` 버튼이 나타납니다.**

1. 그 버튼으로 들어가 PIN(`1214`) 입력
2. 크루원 탭에서 본인 이름을 등록하고 비밀번호 정하기
3. 로그인 화면으로 돌아가 그 계정으로 로그인

크루원이 한 명이라도 등록되면 이 버튼과 무인증 접근은 **자동으로 사라집니다.**
(설정 확인이 실패하면 안전하게 잠그는 쪽으로 동작합니다.)

## 로그인 · 비밀번호

크루원은 **이름 + 비밀번호**로 로그인합니다. 로그인은 한 번 하면 **1년간 유지**됩니다.
기간은 `src/lib/auth.ts` 의 `SESSION_DAYS` 값입니다.

`관리자 → 크루원` 탭에서 이름 옆 `비밀번호 정하기`를 누르면 됩니다.
- 외우기 쉬운 임시 비밀번호가 자동으로 만들어져요(`새로 뽑기`로 다시 뽑을 수 있어요).
- 저장하면 `전달용 문구 복사` 버튼이 뜹니다. 카톡으로 그대로 보내면 돼요.
- **저장하는 순간 암호화되어 다시 열어볼 수 없습니다.** 잊어버렸다면 새로 정해주면 됩니다.

운영자가 정해준 것은 **임시 비밀번호**입니다. 크루원이 처음 로그인하면 홈 화면에
"임시 비밀번호를 쓰고 있어요" 안내가 뜨고, 본인 비밀번호로 바꾸도록 유도합니다.
바꾸고 나면 운영자도 그 비밀번호를 알 수 없습니다 — 벌금이 걸린 규정 동의 기록이
"본인만 할 수 있는 행위"가 되도록 하기 위한 설계입니다.

비밀번호는 `member_credentials` 테이블에 따로 보관하고, 이 테이블은 RLS 정책을
하나도 만들지 않아 **앱의 공개 키로는 접근할 수 없습니다.** 확인은 서버에서만 이뤄집니다.

## 회원 / 비회원

`관리자 → 크루원` 탭에서 사람마다 **회원 / 비회원**을 지정합니다. 버튼 하나로 바꿀 수 있어요.
투표·공지·규정·캐치마이크는 **둘 다 똑같이** 쓸 수 있고, 차이는 회비뿐입니다.

- **회원**: 매달 정액 (회차의 `회원 금액`)
- **비회원**: 참여한 횟수 × 1회 참여비

비회원에게 회비를 받을지는 **회차마다 켜고 끌 수 있습니다.**
새 회차를 만들 때 체크하거나, 이번 회차 옆의 `비회원 참여비 안 받음` 버튼으로 바로 바꿀 수 있어요.

- **끈 상태**: 비회원은 회비 명단에서 빠지고, 본인 화면에도 "이번 회차는 회비가 없어요"만 보입니다.
- **켠 상태**: 회비 화면에서 비회원 이름 옆 `− 0 +`로 참여 횟수를 세면 자동 계산됩니다.

참여한 **날짜**는 기록하지 않고 횟수만 셉니다.

## 회비 입금

카카오뱅크는 개인이 쓸 수 있는 계좌 조회 API를 공개하지 않습니다.
(오픈뱅킹은 사업자 등록된 이용기관만 신청 가능하고, 모임통장은 상세 내역 조회도 막혀 있습니다.)
그래서 **입금 알림을 보고 허브에서 이름을 탭해 체크**하는 방식입니다.

수고를 줄이기 위해 크루원이 직접 알리는 흐름을 넣었습니다.

- 크루원 화면 맨 위에 **모임 계좌(카카오뱅크 3333315776031)** 와 복사 버튼이 있습니다.
- 송금 후 `보냈어요`를 누르면 상태가 "확인 대기중"으로 바뀝니다.
- 운영자 화면 상단에 **확인 대기 N건**으로 모이고, `확인, 납부 완료` 또는 `아직 안 들어옴`으로 처리합니다.
- 계좌번호는 `src/app/dues/page.tsx` 위쪽의 `ACCOUNT` 값에서 바꿉니다.

## 투표

`관리자 → 투표` 탭에서 만들고 수정하고 집계를 봅니다. 크루원은 `/vote` 에서 응답만 합니다.

한 투표 안에 **질문을 여러 개** 둘 수 있고, 질문마다 유형을 고릅니다.

- **하나만** — 참석/불참처럼 하나만 고르기
- **여러 개** — 가능한 날짜, 하고싶은 활동처럼 복수 선택
- **주관식** — 기타 의견

기존에 쓰던 두 앱(모임 참석 체크 `vote-one-pearl`, 참여 현황 체크 `rsvp`)의 기능을
모두 흡수했으므로 그 앱들은 정리해도 됩니다.

집계 화면에서는 보기별 인원·명단·미응답자를 보고, `집계 복사`로 카톡에 붙여넣거나
`PDF로 저장`으로 인쇄용 표를 뽑을 수 있습니다.
(인쇄 창에서 대상을 'PDF로 저장'으로 고르면 파일로 받습니다.)

## 일정

`관리자 → 일정` 탭에서 이름·시작·종료·장소를 넣어 등록합니다.
홈에는 다가오는 2개, 마이에는 5개까지 보입니다.

**참석 응답은 받지 않는 알림용**입니다. 참석 여부를 물어보려면 투표를 만들어주세요.

## 가입 · 비밀번호 재발급 요청

로그인 화면에서 **회원가입 요청**(이름 + 생년월일)과 **비밀번호 재발급**을 보낼 수 있습니다.
요청이 오면 `관리자 → 요청` 탭에 쌓이고, **운영장으로 지정된 사람의 기기에만 푸시 알림**이 갑니다.

운영장이 요청을 보고 크루원 탭에서 이름을 추가하거나 비밀번호를 새로 정한 뒤,
`처리 완료`를 누르면 목록에서 사라집니다.

## 관리자 접근

- **운영장으로 지정된 사람**은 PIN 없이 바로 관리자 화면에 들어갑니다.
- 그 외에는 PIN(`1214`)을 한 번 입력하면, 그 기기에서는 다시 묻지 않습니다.

## 크루 규정 위키

`관리자 → 규정` 탭에서 카테고리를 만들고 그 안에 규정·매뉴얼을 작성합니다.

- 규정마다 **누구에게 보여줄지** 고를 수 있어요.
  아무도 안 고르면 전체 공개, 한 명이라도 고르면 그 사람에게만 보입니다.
  크루원 화면에는 자기에게 해당되는 규정만 나오고, 본인 전용에는 `나에게만` 배지가 붙어요.
- 각 규정에는 **버전**이 있습니다. 수정할 때 "다시 동의받아야 해요"를 체크하면 버전이 올라가고,
  대상 모두에게 다시 `확인 필요` 배지가 뜹니다. 오타 수정이면 체크를 풀면 돼요.
- `동의 현황`으로 누가 동의했는지 보고, `미동의자 태그 복사`로 단톡방 문구를 만들 수 있어요.
- `숨기기`로 작성 중인 초안을 크루원에게 안 보이게 할 수 있어요.

## 기간내 미확인 체크 (관리자 전용)

`관리자 → 미확인` 탭. 크루원 화면에는 보이지 않습니다.

- 마감이 지난 투표에서 **응답하지 않은 사람이 자동으로 잡힙니다.**
- `카톡 태그 문구 복사`로 `@이름 @이름 ...` 형태를 클립보드에 담아 단톡방에 붙여넣습니다.
- **3회가 쌓이면 벌금 5,000원**이 표시됩니다. `벌금 냈어요`를 누르면 3회 단위로 정산되고 남는 건 이월돼요.
- 기준값은 `src/components/admin/StrikesPanel.tsx` 의 `FINE_PER_UNIT`, `STRIKES_PER_FINE` 입니다.

> 웹에서는 공지를 실제로 **읽었는지**까지는 알 수 없어요(푸시 수신 여부만 알 수 있습니다).
> 그래서 마감이 있는 투표의 미응답을 기준으로 잡고, 나머지는 직접 기록하는 방식입니다.

## PWA (홈 화면에 앱처럼 설치)

배포 후 **사파리(아이폰) / 크롬(안드로이드)**로 열고 "홈 화면에 추가"를 누르면
아이콘이 생기고 주소창 없이 전체화면 앱처럼 열려요.

⚠️ **카카오톡 인앱 브라우저에서는 "홈 화면에 추가"도, 푸시 알림도 안 돼요.**
크루에 안내할 때 "카톡 말고 사파리/크롬으로 열어주세요"를 꼭 같이 전달해주세요.

아이콘을 바꾸려면 `public/icon-*.png` 를 교체하거나 `scripts/generate_icons.py` 를 수정하세요.
